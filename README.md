# Fisheye Lab

フルサイズ36×24mm、7〜15mmの理想魚眼投影を試すブラウザ内シミュレーターです。

## モード

- シンプル：焦点距離・人数・ポーズ・撮影プリセット・タッチ移動を中心に表示。
- 詳細：投影方式、画角、カメラ座標、最短距離の目安、レンズ資料や歴史も表示。

切り替えても現在の構図を保持し、選択したモードは端末に記憶します。

## 操作

プレビューのドラッグ／スワイプで向き、Shift＋ドラッグで平行移動、2本指のピンチで前後移動。W/Sで前後、A/Dで左右、Q/Eで上下移動。俯瞰・側面の位置図もドラッグできます。スマホでは移動ボタンの長押しに対応します。

## 画像保存

1200×800pxで再計算したPNGを、プレビュー付きの保存画面からダウンロードできます。対応端末ではファイル共有メニューを使用でき、非対応の場合は画像の長押し保存も可能です。長押し保存時のファイル名の扱いは端末に依存します。

保存名の各要素：焦点距離、投影方式、最大画角、シーン、人数・ポーズ、人物配置d、表面距離near、左右位置x、高さh、前後位置z、yaw/pitch/roll、ガイド有無、端末のローカル日時（ミリ秒）、ランダムID。

保存したPNGを別の画像生成AIへの参照画像などとして使う次の作業は、利用者がアプリ外で行います。画像生成や外部AIサービスへの送信は実装していません。

## 実装

`dist/`を静的配信してください。依存インストールやビルドは不要です。操作中600×400px、保存時1200×800pxでレイを計算します。画像入力は横縦比2:1の正距円筒360°パノラマを想定し、端末内で処理します。

理想レンズと簡略化した成人比率のマネキンによる構図確認用です。メーカー固有の歪曲、近接光学、合焦や収差は再現しません。

## GitHub Pages

GitHubリポジトリの Settings → Pages → Source を **GitHub Actions** に設定してください。`main`へのpushで`.github/workflows/pages.yml`が`dist/`を公開します。相対パスのためプロジェクト用URLにも対応しています。

複数人は通常のポーズで中心間隔60cm、横向き寝姿では150cm。3人の前後差は10cm、大人数の行間は通常68cmで、まとまった構図を作れる配置です。

## キャラクターと共有画像

「スリープしない君」のMacくんと同じ、ふわふわフェルトのお友達シリーズ。ぎょぎょ太郎は水色のお魚、クリーム色のおなか、オレンジの背びれ、おなかの大きな魚眼レンズ、緑の瞳とにっこりした口が特徴です。

- 透過原画：`dist/assets/gyogyotaro-plush.png`（RGBA）
- OGP：`dist/assets/ogp.png`（1200×630）
- favicon：`dist/favicon.ico`、`dist/assets/favicon-32.png`
- ホーム画面用：`dist/assets/apple-touch-icon.png`

キャラクターは組み込み画像生成ツールで作成。共通プロンプト：同じふわふわのウールフェルト素材、丸い造形、クリームの大きな目と深緑の瞳、刺繍のようなにっこり笑顔、やさしい光。魚眼レンズをおなかに持つ水色の魚、オレンジの背びれ。単体・背景透過、文字なし。
